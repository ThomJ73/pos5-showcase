.NET · Windows

Wo der Browser Hardware trifft

POS5

pos5service

Windows-Dienst mit lokalem Hardware-Webserver für Drucker, Schublade & Display (OPOS).

EFT-Terminals

Protokoll-Module für SIX TIM, ZVT, OPI und weitere Terminals.

Updater & MSI

Automatische Client-Updates mit Statusmeldung an Django, Installer per WiX.

Das Web-GUI ruft per JavaScript den lokalen .NET-Hardwareserver auf – so druckt der Browser Belege, öffnet die Schublade und startet EFT-Zahlungen.
